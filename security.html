Security

How Phaser handles your company's documents.

  • Company separation. Each company's data is kept apart from other companies'. The database enforces it, and automated tests check it on each change.
  • AI models. Phaser drafts with Anthropic's Claude models and indexes your documents for search with Cohere's embedding model. Both run through Amazon Bedrock, in Keramas's own AWS account, set to zero data retention. Your content is not shared with either provider and is not used for training.
  • Hosting. Amazon Web Services, United States. Connections use HTTPS, and the database is encrypted at rest.
  • Sign-in. Single sign-on with Google Workspace. Microsoft Entra ID is being added. Phaser does not hold passwords.
  • Staff access. Limited to named Keramas staff, and logged.

For security-related questions, email security@keramas.ai.
